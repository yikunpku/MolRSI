01 / The method

Two loops.
A better search policy.

Human scientists draw on past successes and failures to decide what to try next. MolRSI connects the optimization of today’s workflow with the way it searches on the next task.

01

Inner loop: improve the workflow

Select, evaluate and refine workflows for the current task. Each result provides feedback about what works and what needs to change.

02

Outer loop: improve how to search

Carry experience across tasks. Persistent memory guides future workflow selection, refinement, resource allocation and repair.

Both loops update shared memory

Solutions. Refinements. Execution feedback.
Experience becomes guidance for the next search.

02 / Learning from experience

Does prior experience help?
